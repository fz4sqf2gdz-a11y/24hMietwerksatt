# Einblicke – Vorher/Nachher Fotos

Lege JPG/WEBP hier ab. Die Website lädt sie in der Sektion **#einblicke**.

## Dateinamen (exakt so verwenden)

### Sandstrahlen
| Datei | Inhalt |
|-------|--------|
| `sandstrahl-vorher-01.jpg` | Rostiger Unterboden / Achse |
| `sandstrahl-vorher-02.jpg` | Rost an Federbein / Aufhängung |
| `sandstrahl-arbeit-01.jpg` | Sandstrahlen in Arbeit (Techniker) |
| `sandstrahl-nachher-01.jpg` | Sauberer / versiegelter Unterboden |
| `sandstrahl-nachher-02.jpg` | Glänzende schwarze Versiegelung |

### Trockeneis
| Datei | Inhalt |
|-------|--------|
| `trockeneis-vorher-01.jpg` | Verschmutzter Motorraum / Unterboden |
| `trockeneis-nachher-01.jpg` | Nach Reinigung |

### Versiegelung
| Datei | Inhalt |
|-------|--------|
| `versiegelung-vorher-01.jpg` | Vor Versiegelung (Rost/Altbitumen) |
| `versiegelung-nachher-01.jpg` | Frisch versiegelt (schwarz glänzend) |
| `versiegelung-nachher-02.jpg` | Querträger / Achse versiegelt |

### Klimaservice
| Datei | Inhalt |
|-------|--------|
| `klima-service-01.jpg` | Klimaservice-Gerät / Auffüllung |

## Fehlende Bilder

Wenn eine Datei fehlt, zeigt die Website ein dezentes Platzhalter-Icon – kein Fehler.

## Komprimieren (empfohlen)

```bash
# z.B. mit sips auf dem Mac (max 1920px Breite)
sips -Z 1920 sandstrahl-vorher-01.jpg
```

Ziel: unter **500 KB** pro Bild für schnelle Ladezeit.
