Fotos und Videos für die Wohnwagen-Seite hier ablegen.

- Videos: `sprite.mp4` (Swift Sprite, Bj. 2017) und `bailey.mp4` (Bailey, Bj. 2011) nennen – sie werden auf der Wohnwagen-Seite automatisch eingebunden, sobald die Dateien da sind.
- Achtung: `*.mp4` ist in `.gitignore` – Videos landen nicht auf GitHub, sondern müssen per Cyberduck direkt auf den Server geladen werden.
- Fotos (Außen, Bad mit Dusche, Küche, Schlafbereich) ebenfalls hierher, dann die Platzhalter in `wohnwagen/index.html` ersetzen.
